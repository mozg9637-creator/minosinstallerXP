# miniOS — инструменты записи

В комплекте два `.exe`-файла. Образ `miniOS.iso` уже встроен внутрь обоих — скачивать ничего не нужно.

## Файлы

| Файл | Что делает |
|---|---|
| `miniOS_Installer.exe` | Просто копирует `miniOS.iso` в папку на компьютере (по умолчанию — на Рабочий стол). Ничего не стирает. |
| `miniOS_Deployer.exe` | Записывает `miniOS.iso` на выбранный жёсткий диск/USB-флешку (посекторно, делает загрузочным) или на CD/DVD. **Стирает всё содержимое выбранного устройства.** |

Если просто нужен файл образа — используй `miniOS_Installer.exe`.
Если нужно, чтобы система реально загружалась с диска/флешки — используй `miniOS_Deployer.exe`.

## miniOS_Deployer.exe — подробнее

### Требования
- Windows XP SP2/SP3 и новее (32-бит и 64-бит).
- Права администратора — запускай через **«Запуск от имени администратора»**.
- Для CD/DVD-записи с корректной загрузочной структурой на Windows 7 и новее используется встроенный `isoburn.exe`. На чистой Windows XP системного инструмента для burn ISO нет — потребуется стороннее ПО (например, ImgBurn) в режиме «Write image file to disc».

### Как пользоваться
1. Запусти `miniOS_Deployer.exe` от имени администратора.
2. Выбери, куда писать: **«Жёсткий диск / USB-накопитель»** или **«CD/DVD-дисковод»**.
3. В списке выбери нужное устройство. Список показывает размер и модель — **внимательно проверь**, что выбран правильный диск.
4. Нажми **«Записать miniOS»**.
5. В окне подтверждения введи слово **УДАЛИТЬ** (это защита от случайной записи не туда) и нажми «Записать».
6. Дождись завершения — прогресс отображается на полосе загрузки.

### ⚠️ Важно
- Запись **необратимо стирает все данные** на выбранном устройстве.
- Если пишешь на встроенный жёсткий диск ноутбука/ПК — убедись, что это точно тот диск, который нужен: нумерация физических дисков (`Диск 0`, `Диск 1`...) не всегда совпадает с буквами дисков в проводнике.
- Не отключай флешку/не выключай питание до появления сообщения «Готово».
- Программа не тестировалась на реальном железе разработчиком — перед использованием на важных данных попробуй сначала на некритичной флешке.

### Возможные проблемы
| Проблема | Решение |
|---|---|
| «Отказано в доступе» при открытии устройства | Запусти exe от имени администратора |
| Список устройств пуст | Обнови список кнопкой «Обновить»; для старых USB-флешек на XP попробуй другой порт |
| Диск не грузится после записи | Проверь в BIOS/UEFI, что включена загрузка с этого носителя (Legacy/CSM для BIOS-режима) |
| Нужна запись на CD на чистой XP | Установи ImgBurn или CDBurnerXP и используй режим записи образа диска |

## miniOS_Installer.exe — подробнее

1. Запусти файл.
2. Выбери папку установки (по умолчанию — Рабочий стол).
3. Нажми «Установить».
4. По завершении файл `miniOS.iso` будет лежать в выбранной папке — его можно записать любой сторонней программой на диск/флешку.

Есть деинсталлятор (`Uninstall.exe`) в папке установки.
